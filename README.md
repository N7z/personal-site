# Personal Site

This was a fun project made in a day, <br>
it's plain html and css with some gifs slapped into it.

Access live website in https://zpaulin.com.

# Features

- Integration with last.fm via [this public api](https://soft.thran.uk/last-played.html) to get my last played song;
- Integration with [hitwebcounter.com](https://www.hitwebcounter.com/) to get the visits count;
- Really cool Y2K aesthetic (early 2000's);
- Stamps, blinkies and gifs everywhere.
